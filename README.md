# Simulation code for Moiré in a twisted oxide bilayer

Supplemental code repository for DOI:10.1038/s41586-026-11330-9

Representative example code for 

(i) using and analyzing the machine learning interatomic potential

(ii) ab initio scanning transmission electric microscopy simulations

(iii) input files to be used for phase-field simulations (in Ferret: see https://github.com/mangerij/ferret)
